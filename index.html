Ricoh-Drive-Backup

Ricoh-Drive-Backup is a personal-use tool that backs up photos from a Ricoh GR camera SD card to the owner's own Google Drive.

It runs on the owner's iPhone using the Scriptable app. When the SD card is connected, it reads JPG photos from the camera's 302RICOH folder, checks the owner's Google Drive folder for files with the same name and size, and uploads only new photos. Photos already in Drive are skipped, so no duplicates are created.

The app is for the owner's personal use only. It does not collect, share, or sell any data, and it does not show ads. Google account credentials are stored only on the owner's iPhone, in the iOS Keychain, and are used only to access the owner's own Google Drive.
